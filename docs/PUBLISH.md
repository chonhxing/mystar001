## 一句话简介（30 字内，后台"简介"字段直接可用）

一张八轴命途图谱，看你的性格最像哪个角色。

备选：

- 填一个生辰，看看你命途最像谁。
- 60 个角色里，谁和你的性格共振最强。

## 长简介（120 字内，后台"详细介绍"可用）

每个人心里都有一个"最像我"的角色。填一个生辰、答几道没有标准答案的问题，
我们把它算成一张八轴的命途图谱，再从 60 个动漫、影视、游戏角色里，
找出与你共振最强的那一个 —— 以及那个你"带不动"的相反命途。
全部计算在本机完成，不收集你的生辰。

## 详细介绍（约 300 字）

「我推的星运」把一个人的性格写成一张**八轴图谱**：光与影、秩序与混沌、羁绊与孤高、
炽热与冷静、天命与自立、温柔与锋利、执念与随性、燃尽与庇护。
八根轴各取一个 0~100 的数值，就成了一张只属于你的形状。

图谱由真实算法算出，不是随机数：太阳与月亮的黄经、按出生地经纬度估算的上升、
干支四柱、生命灵数，按权重加权到同一组轴上。然后拿这张形状去和 60 个角色做**形状匹配**，
找出和你最像的那一个，也告诉你最不像的那一个为什么"带不动"。

你可以只填生辰直接看结果，也可以再答 10 / 20 / 30 / 50 道没有标准答案的问题，
让图谱更贴近你。玩过之后，遇到的角色会进图鉴，每次结果都留在记录里。

生辰只存在你的手机上，不会上传；没有登录页，进入即可玩。

## 玩法

1. **填生辰** —— 日期、时辰（不知道可以留空）、出生地（中国地区三级，含港澳台）。
   不想填也行，有"随机来一次"。
2. **选题目数量** —— 10 / 20 / 30 / 50 道，题目从题库里按轴分层抽取；
   其中一部分题**可以多选**（选项数量也不固定）。
3. **本机计算** —— 图谱和匹配在手机上几毫秒算完，不需要等网络。
4. **看结果** —— 命途图谱全相、八轴坐标、为什么是 TA、没有带入的命途、今日提示。
5. **收集** —— 图鉴（60 个角色）、匹配记录、个人资料卡（可存多份，一键再玩）。

## 特色

- **真算法**：太阳/月亮黄经、上升点球面解、干支四柱、生命灵数 → 八轴向量
- **60 个角色**，形状匹配而非数值距离，所以不会总是同一个角色霸榜
- **题库 1113 道**（含 131 道多选），按轴分层抽样 —— 只答 10 道也覆盖全部八根轴
- **答 50 题和答 10 题对图谱的影响力一样**，多答只是更准（权重按题量归一）
- **生辰不出手机**：姓名/生辰/出生地只存本机
- **没有登录页**：进入即玩，微信静默登录，只用于记录充值和解锁
- **AI 生成内容有明确标识**（合规要求，不可删除）

## 目标用户

16~30 岁，看动漫、玩游戏的年轻人；喜欢角色测试、命运隐喻和收集玩法。

## 主界面风格（美术口径）

> 这一节是**照着代码里的设计令牌写的**（`src/js/theme.js`），不是描述性形容。
> 以后加截图、加素材、找外包画图，都按这里对齐，画面才不会跑偏。

### 一句话定位

**深空底 + 星尘 + 暗金。** 安静的夜空感，暖金做主体，紫色做气氛。
偏"高级感"而不是"热闹卡通"——所以没有高饱和配色、没有描边卡通字、没有白底。

### 色板

| 用途 | 变量 | 色值 |
| --- | --- | --- |
| 页面底色（上 / 中 / 下） | `COLOR.bg` / — / `bgDeep` | `#0B0A1F` / `#100D26` / `#08071A` |
| 卡片面板 | `COLOR.panel` | `rgba(255,255,255,0.045)` |
| 描边（金 / 白） | `COLOR.line` / `lineSoft` | `rgba(232,200,122,0.18)` / `rgba(255,255,255,0.08)` |
| 文字四级（主→次→弱→极弱） | `ink` / `ink2` / `ink3` / `ink4` | `#E9E7F7` / `#A9A4C7` / `#6E6A8F` / `#575374` |
| 主色金（亮 / 正 / 深） | `goldLight` / `gold` / `goldDeep` | `#FFE9AE` / `#E8C87A` / `#A87A22` |
| 气氛紫（正 / 浅） | `violet` / `violetLight` | `#8B6CF0` / `#C6B4FF` |
| 辅助色 | `cyan` / `rose` / `green` / `red` | `#63D7E8` / `#F06C9B` / `#7BD88F` / `#E86A6A` |

状态语义：**金 = 主体与强调**，紫 = 气氛与次要，绿 = 有效/正常，红 = 不足/警示。

稀有度四档也走同一套色：传说=金 `#E8C87A`、史诗=紫 `#8B6CF0`、稀有=青 `#63D7E8`、寻常=灰 `#A9A4C7`。

### 字体与字号

**系统无衬线字体**（`sans-serif`），**不带任何字体文件** —— 中文字体包动辄几 MB，
而小游戏主包上限 4MB，不值。字号阶梯（数值是设计稿坐标）：

| 用途 | 变量 | 字号 |
| --- | --- | --- |
| 品牌名 | `hero` | 68 |
| 题干 / 大标题 | `h1` | 52 |
| 卡片主数字 | `h2` | 40 |
| 小节标题 / 按钮 | `h3` | 32 |
| 正文 | `body` | 28 |
| 次要说明 | `small` | 24 |
| 标签 | `tiny` | 21 |
| 极小注释 | `micro` | 19 |

正文行高 1.85 倍（中文好读），标题 1.3 倍。

### 版式与圆角

- 设计稿宽 **750**（等同 rpx），所有尺寸都按这个尺度写，代码里不做设备适配
- 左右留白 **32**，卡片内边距 **28**
- 圆角阶梯：`12 / 20 / 28 / 36 / 胶囊`
- 间距阶梯：`8 / 16 / 24 / 32 / 40 / 56 / 72 / 96`
- 内容上边界取"刘海下沿"与"右上角胶囊按钮下沿"的**较大值** —— 标题永远不会被胶囊压住

### 界面骨架

| 层级 | 结构 |
| --- | --- |
| 三个主页（主界面 / 图鉴 / 我的） | 顶部（主界面是"账号行"，其余是标题）+ 滚动内容 + **底部导航（高 108）**。没有返回键 —— 主页之间是"切换"，不是"返回" |
| 二级页（答题、结果、角色详情、记录、充值、设置） | 顶部标题 + 返回，底部不放导航 |

主界面顶部那条"账号行"固定不滚动：左边头像 + "我的"，右边显示还剩几次 ——
这两件事是用户进主界面最想知道的，不该藏在滚动内容里。

### 组件语言

- **卡片**：半透明面板 + 1px 描边。重点卡（今日提示、可用次数）额外加一层从顶部向下衰减的金色发光
- **小标题**：金色竖条（金→紫渐变）+ 文字
- **按钮**：主按钮是金色三段渐变的胶囊，文字用深褐 `#2A1E05`（保证金底上的可读性）；
  次要动作用金色描边的"幽灵按钮"；危险操作（清空记录）用红色
- **标签**：胶囊小标签，按稀有度换色
- **图表**：共振环（从 0 涨上去的圆环）、八轴条（每轴一条，标出两极）
- **背景**：竖直渐变 + 三处星云（左上紫、右上青、底部金）+ 星点，顶部一段刻度环；
  **主界面的星空一直在动**（其他页面静止，省电）

### 动效

- **静止页面不重绘**（脏标记渲染）：这是刻意的省电设计，低端机不发烫
- 按钮按下整体缩 3% + 发光，点击带一次轻微振动
- 数字和共振环有"从 0 涨上去"的填充动画
- 场景切换淡入上浮

### 加美术素材时的三条禁忌

1. **不要放真实人物立绘。** 引用作品的角色用官方立绘有实实在在的版权风险 ——
   这也是现在全用"程序化星徽"的原因（按角色 id 生成同心多边形 + 星芒 + 首字，永远同一个纹样）
2. **不要用高饱和大色块和白底**，会和深空底打架。图片请用深色底或透明底
3. **图片只能是 png / jpg** —— webp 不在小游戏的文件白名单里，上传会失败

## 提审要点（**逐条看，这几条最容易被打回**）

### 1. 类目：这是**小游戏**，不是小程序

提审走"小游戏"通道；工程根目录是 `game.json` + `game.js`（Canvas 自绘）。

### 2. 后台**所有**文案都不能出现这些词

包括：游戏名称、简介、更新说明、截图上的字。

| 不能出现 | 该用 |
| --- | --- |
| 占卜 | 匹配 |
| 算命 | 性格分析 |
| 抽签 | 随机匹配 |
| 运势 | 今日提示 |
| 吉凶 | 状态 |
| 预言 | 提示 |
| 占星 / 命盘 | 图谱 |
| **星座运势** | ⚠️ 这是官方点名的示例词，**不能当替换目标** |

依据：《微信小程序平台运营规范》常见拒绝情形 3.2.4 —— "不能存在测试类内容；
示例：算命，抽签，星座运势等"。代码里所有用户可见文案都过 `config/copy.js` 一处出口，
`npm run check` 会把上面这些词当**失败**报出来。

### 3. 用户隐私保护指引里必须声明

| 收集项 | 用途 | 是否上传 |
| --- | --- | --- |
| 微信昵称、头像 | 在个人中心展示 | **否**（只存本机） |
| 出生日期 / 时间 / 出生地 | 本机算法计算 | **否**（只存本机） |

两者都不共享给第三方。**在后台声明之前，"用微信头像"那个按钮在真机上不会有反应**
（平台会拦掉），代码里已经做了失败提示。

⚠️ 如果保留默认的 AI 解读（会把干支四柱发给模型服务，而四柱可反推出生时刻），
那就属于"向第三方提供"，**需要如实披露**；想省掉这层麻烦就把
`config.PRIVACY.SEND_PILLARS_TO_AI` 改成 `false`。

### 4. 提审素材清单

- [x] 游戏图标（见下）
- [ ] 截图 4~5 张（建议：首页、答题页、结果页图谱、图鉴、个人中心）
- [ ] 一句话简介 + 长简介（本文档最上面）
- [ ] 版本更新说明

## 图标

| 项目 | 值 |
| --- | --- |
| 主文件 | `我推的星运-游戏图标-144.png` |
| 尺寸 / 格式 | **144 × 144 · PNG**（官方建议尺寸，也是效果最好的格式） |
| 体积 | 25 KB（上限 2 MB） |
| 不透明 | ✅ 全部像素 alpha = 255（有透明像素的话平台垫的底色会透出来） |
| 备用 | `我推的星运-游戏图标-512.png`（分享卡、后台某些位置要用大图） |

### 图上画了什么

| 元素 | 含义 |
| --- | --- |
| 八角星（四长四短） | **八轴命途图谱** —— 游戏的核心 |
| 倾斜的星轨 + 轨道上的小星 | 命途的走向；那颗小星就是"与你共振的角色" |
| 八边形虚线 + 八个顶点 | 八根轴围成的图谱轮廓（放大才看得清，缩小后自然隐去） |
| 深空底 + 暗金 + 紫 | 和游戏内 UI 完全相同的一套色板（见上面「主界面风格」） |

**图标和界面是同一套视觉语言**：主界面顶部的星徽、结果页的共振环、角色卡的纹样，
用的都是这颗星和这套配色。所以图标缩到列表里，用户点进来不会有"换了个游戏"的感觉。

### 怎么改 / 怎么重新生成

图标是**程序化生成**的（这个项目零依赖，连图标也不依赖设计源文件）：

```bash
node tools/make-icon.js              # 重新生成 144 和 512
node tools/make-icon.js --size=512   # 只出某个尺寸
node tools/preview-icon.js           # 自检：打印字符画 + 对比度 + 不透明度
```

配色、构图、元素位置全在 `tools/make-icon.js` 里，改完跑一次 `preview-icon.js`
就能确认"缩小到 48px 还认不认得出"（小程序列表里图标就是那么小）。
